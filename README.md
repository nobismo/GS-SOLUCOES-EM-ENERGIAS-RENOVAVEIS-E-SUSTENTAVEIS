# Funcionamento do Sistema

O sistema realiza a leitura contínua dos sensores simulados e monitora os seguintes parâmetros:

## Temperatura

Obtida através do sensor NTC.

## Energia

Simulada por um potenciômetro representando a energia gerada por painéis solares.

## Comunicação

Definida automaticamente com base na disponibilidade energética do sistema.

## Status Operacional

Exibido em tempo real no display LCD e no monitor serial.
